# كافيه الوحدة 12: المساحات وملف الأوتوكاد

المصدر: مخططان PDF من العميل (`source/ground_floor.pdf` الدور الأرضي، `source/upper_floor.pdf` الدور الأول علوي)،
مطبوعان من أوتوكاد بـ Microsoft Print to PDF. مقياس الرسم تحقق على 28 بُعداً، وأقصى فرق 4 ملم.

## المساحات (للتسعير)

| المنطقة | الحساب (من أبعاد المخطط) | المساحة م² |
|---|---|---|
| الدور الأرضي (داخلي) | 10.2 × 18.6 | 189.7 |
| الميزانين العلوي (داخلي) | 12.15 × 26.02 | 316.1 |
| التراس العلوي | 6.45 × 26.02 + بروز 1.5 × 10.2 | 183.1 |
| **مجموع العلوي مع التراس** | | **499.2** |
| **الإجمالي: أرضي + علوي + تراس** | | **688.9** |

- مكتوب على المخطط 189 للأرضي و483 للعلوي. 483 = (12.15 + 6.45) × 26.02 = الداخلي مع التراس بدون البروز (15.3 م²).
- «خدمات خارجية» خلف المحل مكتوب عليها 121 م²، وما انحسبت.
- الجلسات الأمامية محسوبة لحد الخط الأصفر المتقطع على امتداد جدار المحل اليمين.
- الارتفاعات: الأرضي 5 م، العلوي 4 م.

## ملف الأوتوكاد `Coffee12_Plans.dxf`
- الوحدة متر (1 وحدة = 1 م)، صيغة DXF R2010 (AutoCAD 2010 وأحدث). للحفظ DWG: Save As.
- نقطة الأصل (0,0) = زاوية الكافيه الداخلية عند الواجهة الزجاجية، الجدار اليسار.
- الدور العلوي كان مطبوعاً مدوّراً في الـ PDF، ورُجّع معدولاً. جبهته (Y=0) وظهره (Y=18.6) على نفس خطوط الأرضي،
  ومحطوط 25 م يمين: `MOVE` بمقدار (‎-25,0) بيطابقه فوق الأرضي.
- الطبقات: `GF-*` الأرضي، `UF-*` العلوي، حسب اللون. الأبعاد على `*-DIMS`. النص العربي كما في الأصل على
  `*-TEXT-PDF`، ونسخة قابلة للتعديل على `*-TEXT-EDIT` (مطفأة). حدود المساحات مع أرقامها على `AREA-*` (مطفأة).
